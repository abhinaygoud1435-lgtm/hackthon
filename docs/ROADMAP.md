# MIRA PROJECT ROADMAP & FUTURE PHASES

---

## Phase 1 — Hackathon MVP (Current Initialization Scope)
- Basic 5-Agent parallel development setup.
- Core UI layout with responsive Assistant screen, avatar display, soundwaves, and confirmation modals.
- Speech-to-text abstraction & LLM command parser for 11 core intents.
- Android AccessibilityService integration for YouTube navigation, scrolling, back button, and screen text extraction.
- Contact lookup, phone call preparation, SMS, and Email intent dispatchers.
- Voice TTS engine with fallback and animated avatar synchronizer.

---

## Phase 2 — Biometric Presence & Identity Verification
- **Live Face Verification**: Camera stream integration for face recognition before executing sensitive actions.
- **Liveness Detection**: Anti-spoofing blink/head-movement check.
- **Speaker Verification**: Voice print matching to restrict voice commands to authorized owner.

---

## Phase 3 — Deep Screen Intelligence & App Ecosystem Expansion
- **Multi-App Accessibility Automation**: WhatsApp, Gmail, Google Maps, Uber, Spotify, Instagram.
- **Advanced Screen Understanding**: OCR + Vision model fallback for custom non-standard UI widgets.
- **Contextual Conversation Memory**: Multi-turn dialogue context retention.

---

## Phase 4 — Autonomous Personal AI Agent
- **Proactive Assistant**: Context-aware recommendations (e.g. calendar reminders, traffic updates, smart home triggers).
- **Custom Voice Training Pipeline**: On-device user voice cloning.
- **Offline Edge Inference**: On-device SLM execution for zero-latency command parsing.
